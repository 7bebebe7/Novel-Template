# Novel-template

# EN:

The mod was created as a template for new mechanics.

The factory mod adds two buttons to the menu that display "frames."

Taking the code and using the mod for private purposes is allowed, but if it's a public mod, it's prohibited.

# How it works:

1. Copy the code and paste it into your *main.js (or other)*

2. Change the *"ModName"* variable to the name of your mod (the one in the mod.json file), otherwise the backgrounds won't display.

3. Add your *frames* to the *scenes* array. Frames should store *3* parameters: *name*, *text*, *bg*

4. Use the **openNovel(num)** function to open the desired frame and set the desired frame.
