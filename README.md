RU:

мод был создан как шаблон для новоц механики

мод по заводу добавляет 2 кнопки в меню которые показывают "фреймы"

брать код и использовать мод в лисных целях позволено, но если это публичный мод, прошу упомянуть автора

# Как работает:

1. скопируйте код и вставте в свой *main.js(или другой)*

2. измените значение переменной *"ModName"* на название вашего мода (то что в файле mod.json), а иначе фоны не будут отображаться

3. добавляйте свои *frames* в масив *scenes*, frames должен хранить *3* параметра *name*, *text*, *bg*

4. используйте функцию **openNovel(num)** для открытия нужного фрейма, чтобы задать нужный фрейм, укажите номер frame вместо num
